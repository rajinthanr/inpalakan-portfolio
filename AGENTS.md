# Project guidance

Build a mobile-first portfolio for Inpalakan Timbers. Use `README.md` for the user-approved product direction and source albums.

- Keep actual completed work clearly separate from AI-generated concepts.
- Do not claim a timber species, manufacturing method, dimension, price, or project location unless it is verified.
- Optimize for phone browsing and sharing a specific design through WhatsApp.
- Use a stable design code on every project page and in its WhatsApp enquiry message.
- Do not publish the site or change the business's external accounts without the user's authorization.
